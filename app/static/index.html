        BepInEx

        Enable the bundled BepInEx package and upload plugins below. No URL or checksum is required. Changes apply at the next game startup.

        Upload plugins

        Stop the game before uploading. Use trusted plugins compatible with BepInEx. They load at the next startup.

        Deleted plugins

        Deletion keeps a recovery copy outside the BepInEx loading directory and preserves settings. Copies use disk space until removed from shared files.

        Upload individual DLLs without ZIPs or additional files. Replacements require confirmation and preserve one previous version outside the loading directory.

        Plugin configuration files

        Select a text configuration generated by a plugin. Stop before saving and start again to apply it. The editor preserves one previous version.

        UTF-8 files up to 32 KiB in BepInEx/config. The editor does not validate plugin-specific rules. Other configuration directories require SSH access.

        Players and permissions

        Choose a list, add or remove players, then save. A populated permitted list restricts access to those players.

        Names, platforms, and IDs from logs or administrator records. Crossplay IDs may need confirmation in F2. This history does not show who is online.

        Identify or confirm a player

        Copy the ID exactly as shown in the game. The name is your own label. Saving an identity does not grant permissions or change player lists.

        Use the platform ID shown in F2. A 17-digit SteamID64 is also accepted. Do not use join codes or PlayFab connection handles.
